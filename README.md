# Formulário de Indicação — Decorafit

Formulário do Programa de Indicação (nome, telefone, e-mail, CRECI e chave PIX), responsivo para desktop e mobile.

- `index.html` — o formulário, sem dependências além da fonte Inter (Google Fonts).
- As respostas são enviadas para um Google Apps Script que grava na planilha de indicações. A URL do script fica na constante `URL_ENVIO` em `index.html`.
